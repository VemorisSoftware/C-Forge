Hola, C-Forge

C-Forge es un lenguaje compilado con sintaxis en español e inglés. Los archivos tienen extensión .cfv.

// Mi primer programa
mostrar("¡Hola, C-Forge!")

// Variables
sea nombre = "Javier"
sea edad = 20
mostrar("Hola, " + nombre)

Declarar variables

Usa sea para declarar una variable. El tipo se infiere automáticamente.

sea texto_var = "hola"
sea numero_var = 42
sea decimal_var = 3.14
sea bool_var = verdadero
sea lista_var = [1, 2, 3]

Ejecutar un archivo

c-forge mi_programa.cfv

Tipos de datos

  • numero — enteros y decimales (42, 3.14)
  • texto — cadenas ("hola")
  • booleano — verdadero / falso
  • lista — array dinámico ([1, 2, 3])
  • mapa — diccionario ({"clave": valor})
  • nulo — valor vacío

Conversiones

a_numero("42")       // texto → numero
a_texto(42)         // numero → texto
piso(3.9)           // → 3
techo(3.1)          // → 4
redondear(3.5)     // → 4
raiz(16)            // → 4
potencia(2, 10)    // → 1024

Operadores

// Aritméticos
10 + 3   // 13
10 - 3   // 7
10 * 3   // 30
10 / 3   // 3.33...
10 % 3   // 1

// Lógicos
verdadero y falso   // falso
verdadero o falso   // verdadero
no verdadero        // falso

Si / sino

si (edad >= 18) {
    mostrar("Mayor de edad")
} sino si (edad >= 13) {
    mostrar("Adolescente")
} sino {
    mostrar("Niño")
}

Mientras

sea i = 0
mientras (i < 5) {
    mostrar(i)
    i = i + 1
}

Para (for-each)

sea numeros = [1, 2, 3, 4, 5]
para n en numeros {
    mostrar(n * 2)
}

// Con rango numérico
para i en rango(0, 10) {
    mostrar(i)
}

Intentar / capturar

intentar {
    sea n = a_numero("abc")
} capturar(err) {
    mostrar("Error: " + err)
}

Definir funciones

funcion saludar(nombre: texto): texto {
    retornar "¡Hola, " + nombre + "!"
}

mostrar(saludar("Javier"))

Funciones sin tipo de retorno

funcion imprimir_lista(items: lista) {
    para item en items {
        mostrar(item)
    }
}

Funciones como valores

sea doble = funcion(n: numero): numero {
    retornar n * 2
}
mostrar(doble(21))  // 42

Funciones built-in útiles

mostrar(valor)         // imprimir en consola
longitud(lista)        // tamaño de lista o texto
agregar(lista, item)   // agregar a lista (in-place)
leer("Mensaje: ")      // leer input del usuario

Listas

sea lista = [10, 20, 30]
agregar(lista, 40)           // [10, 20, 30, 40]
mostrar(lista[0])            // 10
mostrar(longitud(lista))     // 4

Importar stdlib/lista.cfv

importar "stdlib/lista.cfv"

sea nums = [3, 1, 4, 1, 5]
lista_ordenar(nums)           // ordenar
lista_invertir(nums)          // invertir
lista_contiene(nums, 4)      // verdadero
lst_concat(lista1, lista2)    // concatenar

Mapas (diccionarios)

sea persona = {
    "nombre": "Javier",
    "edad": 20
}
mostrar(persona["nombre"])   // Javier
persona["ciudad"] = "CDMX"  // agregar clave

Importar librerías

Todas las librerías se importan con importar "stdlib/nombre.cfv" al inicio del archivo.

importar "stdlib/matematica.cfv"
importar "stdlib/aleatorio.cfv"
importar "stdlib/fecha.cfv"

mostrar(MAT_PI)                      // 3.14159...
mostrar(aleatorio_entero(1, 100))   // número aleatorio
mostrar(fecha_ahora())               // fecha actual

Juego con SDL2

importar "stdlib/sdl.cfv"

sdl_init(SDL_INIT_VIDEO)
sea win = sdl_ventana("Mi juego", 800, 600, SDL_VENTANA_NORMAL)
sea ren = sdl_renderer(win)

mientras (verdadero) {
    sea eventos = sdl_eventos()
    // ... lógica del juego
    sdl_presentar(ren)
    sdl_esperar(16)
}
sdl_cerrar()
