Learn C-Forge.

A short, practical guide. Every example shows its real output: we run them with C-Forge 4.7.0 on every change to the repository.

Getting started

Install C-Forge with one command (on Windows, use PowerShell):

$curl -fsSL https://c-forge.org/install.sh | sh

Create a file with the .cfv extension:

And run it:

$cforge hello.cfv

Variables and types

Declare variables with let and reassign them with =. The basic types are number, text, boolean (true / false), list, map and null. Convert between text and numbers with to_number() and to_text().

Operators

Arithmetic + - * / %, comparison == != < <= > >= and logical operators as words: and, or, not. + also joins text.

Text

Inside a text, {expression} inserts a value. Write literal braces as \{ and \}.

Conditions and loops

if / else to decide, while to repeat and for … in … to walk through a list.

Functions

Define them with function and return values with return. Functions are values: you can store them in variables and return them from other functions (closures), which remember the variables where they were created.

Lists and maps

Lists use square brackets and start at index 0. Maps store key-value pairs in braces.

Classes

A class groups state and methods. The constructor method runs when the instance is created, and this refers to the current object.

Errors

throw raises an error; try / catch handles it so the program keeps going.

Modules

import "name" loads a module from the standard library. cforge finds it on its own, next to its executable. Module and function names in the standard library are in Spanish.

Included: networking and WebSocket (red, web), databases (db, sqlite, postgres, mysql), cryptography (crypto) and graphics (sdl, gl, juego). Check the project status.

JSON

The json module reads and writes JSON with json_parse() and json_stringify().

C libraries

extern "library" function name(param: type): type declares a function from a C library, and you call it like any other. Types: int, long, number, string, pointer, bool and void. "libc" and "libm" resolve automatically on Linux, macOS and Windows; for other libraries use their name ("sqlite3") or path.

Current limits: up to 8 parameters and no variadic functions such as printf.

Testing

assert(condition, message) stops the program with your message when the condition is false. Run a test file with cforge test.

cforge commands

CommandWhat it does
cforge file.cfvRuns a program.
cforge replOpens an interactive console.
cforge check file.cfvChecks syntax and types without running.
cforge test file.cfvRuns a test file.
cforge fmt file.cfvChecks formatting without changing the file.
cforge new nameCreates a project with main.cfv and cforge.json.
cforge build file.cfv -o appProduces a native executable, with no C compiler or linker. --release strips the code you do not use.
cforge doctorDiagnoses your installation.
