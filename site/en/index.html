Installation

Ready in one command.

The installer downloads the official binary from GitHub, verifies its SHA-256 checksum and installs cforge. Nothing to configure afterwards.

1 · Install (Apple Silicon and Intel)
$curl -fsSL https://c-forge.org/install.sh | sh
2 · Check
$cforge --version
1 · Install (x86_64 and ARM64)
$curl -fsSL https://c-forge.org/install.sh | sh
2 · Check
$cforge --version
Alternative on Debian / Ubuntu: .deb package
$sudo dpkg -i cforge_5.0.0_amd64.deb
1 · Install in PowerShell (Windows 10 or 11, 64-bit)
PS>irm https://c-forge.org/install.ps1 | iex
2 · Open a new terminal and check
PS>cforge --version

FAQ

Straight answers.

Is C-Forge compiled or interpreted?

Compiled. cforge program.cfv compiles it to machine code and runs it instantly; cforge build program.cfv leaves the native executable (Linux, Windows, macOS; --target builds for another platform). The compiler is written in C-Forge and compiles itself.

Do I need to install anything else?

No. The installer sets everything up and cforge build produces executables with no C compiler, assembler or external linker.

Is it as fast as C or C++?

It is on par with Java: primes up to 200,000 + fib(30) takes 73 ms with --release (Java 21: 67 ms; C with gcc -O2: 25 ms). Integer operations are compiled inline and integers proven by the checker skip runtime checks.

Can I use it in production?

Yes, for tools, web services and applications: the compiler, the CLI and the full standard library (including networking, WebSocket, PostgreSQL and MySQL) pass the tests on Linux, Windows and macOS on every change. Critical systems such as banking still need an independent audit. The Status section has the details.

Can I code in Spanish too?

Yes. C-Forge was born in Spanish: sea, funcion, si, mientras, retornar and the rest are exact equivalents of let, function, if, while, return, and you can mix both in the same file. Values and error messages follow the language of your program: true in English, verdadero in Spanish.

How much does it cost? What license does it have?

Downloading and trying it is free. C-Forge is developed by Vemoris Group under a proprietary license: the source is on GitHub to view and evaluate, and using it in production, modifying it or redistributing it requires written permission from Vemoris Group. See the LICENSE for details.

I found a bug, where do I report it?

In the GitHub issues. Including the .cfv file and the output of cforge doctor helps a lot.
