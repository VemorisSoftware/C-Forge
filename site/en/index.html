Installation

Ready in one command.

The installer downloads the official binary from GitHub, verifies its SHA-256 checksum and installs cforge. Nothing to configure afterwards.

1 · Install (Apple Silicon; on Intel Macs it builds from source)
$curl -fsSL https://c-forge.org/install.sh | sh
2 · Check
$cforge --version
1 · Install (x86_64; other architectures build from source)
$curl -fsSL https://c-forge.org/install.sh | sh
2 · Check
$cforge --version
Alternative on Debian / Ubuntu: .deb package
$sudo dpkg -i cforge_4.1.0_amd64.deb
1 · Install in PowerShell (Windows 10 or 11, 64-bit)
PS>irm https://c-forge.org/install.ps1 | iex
2 · Open a new terminal and check
PS>cforge --version

Roadmap

The goal: to stand alongside C, C++, C# and Java.

We take the best of each one to build our own language, simpler and in your language. This is the path, in order.

A 100% C-Forge compiler

Native executables produced by a compiler written entirely in C-Forge. Its core already exists and compiles itself.

Static types and generics

Compile-time type checking, generics and clear errors before running, as in C# and Java.

Memory safety

Ownership and borrowing without a garbage collector, for C-level performance without its memory bugs. Already in the experimental core.

A complete standard library

Networking, HTTP with TLS, threads, databases and cryptography, stable and tested on all three platforms.

C interoperability

Call any C library from C-Forge to tap into the whole existing ecosystem.

Professional tooling

Package manager, a complete language server (LSP) and a debugger.

FAQ

Straight answers.

Is C-Forge compiled or interpreted?

Compiled. cforge program.cfv compiles it to machine code and runs it instantly; cforge build program.cfv leaves the native executable (Linux, Windows, macOS; --target builds for another platform). The compiler is written in C-Forge and compiles itself.

Do I need to install anything else?

No. The installer sets everything up and cforge build produces executables with no C compiler, assembler or external linker.

Is it as fast as C or C++?

Not yet. C-Forge already compiles straight to machine code, but without an optimizer yet; --release optimizations are on the roadmap.

Can I use it in production?

For scripts, tools and learning, yes: the core, the CLI and the stable library pass the tests on all three platforms. Networking, SQLite, cryptography and graphics are still experimental, and C-Forge is not yet certified for critical systems such as banking. The Status section has the details.

Can I code in Spanish too?

Yes. C-Forge was born in Spanish: sea, funcion, si, mientras, retornar and the rest are exact equivalents of let, function, if, while, return, and you can mix both in the same file. Values and error messages follow the language of your program: true in English, verdadero in Spanish.

How much does it cost?

Nothing. C-Forge is open source under the MIT license, developed by Vemoris Group.

I found a bug, where do I report it?

In the GitHub issues. Including the .cfv file and the output of cforge doctor helps a lot.
