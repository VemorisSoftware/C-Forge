Aprende

Aprende C-Forge.

Una guía corta y práctica. Cada ejemplo muestra la salida real: los ejecutamos con C-Forge 3.7.1 en cada cambio del repositorio.

Empezar

Instala C-Forge con un comando (en Windows, usa PowerShell):

$curl -fsSL https://c-forge.org/install.sh | sh

Crea un archivo con extensión .cfv:

Y ejecútalo:

$cforge hola.cfv

Variables y tipos

Las variables se declaran con sea y luego se reasignan con =. Los tipos básicos son número, texto, booleano (verdadero / falso), lista, mapa y nulo. Para convertir entre texto y número usa a_numero() y a_texto().

Operadores

Aritméticos + - * / %, de comparación == != < <= > >= y lógicos en palabras: y, o, no. El + también une textos.

Textos

Dentro de un texto, {expresión} inserta un valor. Para escribir llaves literales usa \{ y \}.

Funciones

Se definen con funcion y devuelven con retornar. Son valores: puedes guardarlas en variables y devolverlas desde otras funciones (closures), que recuerdan las variables de donde nacieron.

Listas y mapas

Las listas van entre corchetes y empiezan en el índice 0. Los mapas guardan pares clave-valor entre llaves.

Clases

Una clase agrupa estado y métodos. El método constructor se ejecuta al crear la instancia y esto se refiere al objeto actual.

Errores

lanzar produce un error; intentar / capturar lo atrapa para que el programa siga.

Módulos

importar "nombre" carga un módulo de la biblioteca estándar. cforge la encuentra solo, junto a su ejecutable.

Experimental: los módulos de red (red, web), bases de datos (db), criptografía (crypto) y gráficos (sdl, gl, juego) todavía pueden cambiar. Revisa el estado del proyecto.

JSON

El módulo json lee y escribe JSON con json_parsear() y json_serializar().

Pruebas

afirmar(condicion, mensaje) detiene el programa con tu mensaje si la condición es falsa. Ejecuta un archivo de pruebas con cforge test.

Comandos de cforge

ComandoQué hace
cforge archivo.cfvEjecuta un programa.
cforge replAbre una consola interactiva.
cforge check archivo.cfvRevisa la sintaxis sin ejecutar.
cforge test archivo.cfvEjecuta un archivo de pruebas.
cforge fmt archivo.cfvRevisa el formato sin modificar el archivo.
cforge new nombreCrea un proyecto con main.cfv y cforge.json.
cforge build archivo.cfv -o appGenera C y lo compila con gcc o clang. Requiere uno de ellos instalado.
cforge doctorDiagnostica tu instalación.
