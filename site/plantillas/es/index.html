Logros

A la altura de C, C++, C# y Java. Hecho.

Todo esto está en la versión {{version}} y lo verifica el CI en Linux, Windows y macOS en cada cambio.

✓ Compilador 100 % C-Forge

Escrito en C-Forge y compilado por sí mismo (Stage 2 = Stage 3 byte por byte). Sin C++, sin libc, sin ensamblador ni enlazador externos.

✓ Tipos estáticos y genéricos

Inferencia local y errores antes de ejecutar en check, build y el editor. Genéricos comptime T.

✓ Memoria acotada

Recolector de basura propio: un ciclo de 2 millones de iteraciones pasa de 1,77 GB a 9 MB de RAM.

✓ Velocidad nativa

Primos + fib(30) en 73 ms, a la par de Java (67 ms) y sin máquina virtual. --release deja "hola" en 34 KB.

✓ Punteros seguros y comptime

*T nunca es nulo y ?T se comprueba antes de usarse. comptime ejecuta código al compilar.

✓ Red y bases de datos nativas

HTTP/HTTPS, WebSocket RFC 6455, PostgreSQL (SCRAM-SHA-256) y MySQL sin libpq ni libmysqlclient, probados contra servidores reales.

Preguntas frecuentes

Respuestas directas.

¿C-Forge es compilado o interpretado?

Compilado. cforge programa.cfv lo compila a código máquina y lo ejecuta al instante; cforge build programa.cfv deja el ejecutable nativo (Linux, Windows, macOS; --target para compilar para otra plataforma). El compilador está escrito en C-Forge y se compila a sí mismo.

¿Necesito instalar algo más?

No. El instalador deja todo listo y cforge build genera ejecutables sin compilador de C, ensamblador ni enlazador externos.

¿Es tan rápido como C o C++?

Ya está a la par de Java: primos hasta 200 000 + fib(30) tarda 73 ms con --release (Java 21: 67 ms; C con gcc -O2: 25 ms). Las operaciones con enteros se compilan en línea y los enteros probados por el verificador no se comprueban en ejecución.

¿Puedo usarlo en producción?

Sí, para herramientas, servicios web y aplicaciones: el compilador, la CLI y la biblioteca estándar completa (incluidas red, WebSocket, PostgreSQL y MySQL) pasan las pruebas en Linux, Windows y macOS en cada cambio. Para sistemas críticos como banca todavía falta una auditoría independiente. La sección Estado lo detalla.

¿Puedo programar en inglés?

Sí. Desde la versión 3.7.2, let, function, if, else, while, for, return, class, try, catch, print y más son equivalentes exactos de sus versiones en español, y puedes mezclarlas en el mismo archivo. Los valores y los mensajes de error siguen el idioma de tu programa: verdadero en español, true en inglés.

¿Cuánto cuesta? ¿Qué licencia tiene?

Descargarlo y probarlo no cuesta nada. C-Forge lo desarrolla Vemoris Group con una licencia propietaria: el código está en GitHub para verlo y evaluarlo, y para usarlo en producción, modificarlo o redistribuirlo se necesita una autorización escrita de Vemoris Group. Los detalles están en LICENSE.

Encontré un error, ¿dónde lo reporto?

En los issues de GitHub. Si incluyes el archivo .cfv y la salida de cforge doctor, mejor.
