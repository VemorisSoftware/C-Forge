Instalación

Listo en un comando.

El instalador descarga el binario oficial desde GitHub, verifica su suma SHA-256 e instala cforge. No hace falta configurar nada después.

1 · Instalar (Apple Silicon; en Mac Intel compila desde el código fuente)
$curl -fsSL https://c-forge.org/install.sh | sh
2 · Comprobar
$cforge --version
1 · Instalar (x86_64; otras arquitecturas compilan desde el código fuente)
$curl -fsSL https://c-forge.org/install.sh | sh
2 · Comprobar
$cforge --version
Alternativa en Debian / Ubuntu: paquete .deb
$sudo dpkg -i cforge_3.7.1_amd64.deb
1 · Instalar en PowerShell (Windows 10 u 11, 64 bits)
PS>irm https://c-forge.org/install.ps1 | iex
2 · Abre una terminal nueva y comprueba
PS>cforge --version

ÁreaEstadoDetalle
Motor nativo de C-ForgeEstableLexer, parser y ejecución de programas .cfv en un ejecutable nativo. Incluye REPL, funciones, closures, clases, excepciones y colecciones.
CLI autónomoEstableEjecución, REPL, versión, ayuda, check, test, fmt, new, init y doctor implementados en el motor nativo. Sin dependencias externas ni Python.
Biblioteca estándar en C-ForgeEstable32 módulos .cfv pasan análisis sintáctico y carga real. Veintiuna suites de pruebas cubren el núcleo y la biblioteca estable. Los módulos de red, bases de datos, criptografía y gráficos conservan estado experimental independiente.
JSON nativoEstableParseo y serialización integrados en el motor.
Red y HTTPExperimentalPrimitivas nativas de sockets y módulo web disponibles para evaluación. Faltan un cliente HTTP completo, TLS uniforme, sandbox y pruebas de carga multiplataforma.
SQLiteExperimentalIntegración opcional mediante el ABI de SQLite. Requiere pruebas de recuperación, concurrencia y migraciones antes de producción.
CriptografíaExperimentalFunciones criptográficas opcionales. No constituyen todavía un módulo certificado para información bancaria.
Gráficos y videojuegosExperimentalMódulos .cfv de SDL2 y OpenGL conservados como experimentales. No se distribuyen ejemplos de juego como evidencia hasta completar pruebas funcionales y empaquetado de recursos.
Núcleo escrito en C-ForgeEn desarrolloEl frontend de C-Forge Core está escrito en .cfv. Stage 1 produce Stage 2, Stage 2 produce Stage 3 y ambos artefactos son idénticos byte por byte. La fase final todavía invoca clang++ para convertir el C++ emitido en código máquina; por eso la toolchain completa aún no es autónoma.
Backends nativos directosEn desarrolloMach-O ARM64, ELF x64 y PE x64 poseen backends Core B6.21. Incluyen funciones, colecciones Core, objetos, módulos, excepciones, movimientos, préstamos compartidos/mutables y destructores LIFO en ámbitos normales o abandonados por retornar/lanzar. El verificador rechaza uso después de mover, movimiento durante préstamo y alias mutable simultáneo antes de emitir. La emisión usa PATH aislado y no llama compilador ni enlazador. Claves dinámicas, despacho dinámico, préstamos que escapan, regiones, llamadas excepcionales en expresiones compuestas y concurrencia todavía están pendientes.
macOS, Linux y WindowsEstableEl núcleo, la CLI y la suite completa de pruebas pasan en CI en Linux x64, macOS ARM64 y Windows x64 en cada cambio. Cada versión publica binarios para las tres plataformas.
Integración con editoresEn desarrolloResaltado y extensión de VS Code disponibles. LSP, DAP y refactorizaciones deben migrarse completamente al toolchain autónomo.
Gestor de paquetes autónomoPlanificadoEl diseño existe, pero el cliente anterior dependía de herramientas externas. Se reimplementará en C-Forge antes de anunciarlo como estable.
Bancos y producción críticaNo certificadoRequiere auditoría profesional independiente, threat model, builds reproducibles y firmados, LTS, recuperación ante fallos y cumplimiento regulatorio.
Hoja de ruta

El objetivo: estar a la altura de C, C++, C# y Java.

Hoy C-Forge ejecuta tus programas con un motor nativo escrito en C++. Este es el camino, en orden, para que compita con los lenguajes de sistemas y de empresa.

Compilador propio

Generar ejecutables nativos sin depender de C++, gcc ni clang. El núcleo del compilador ya está escrito en C-Forge y se compila a sí mismo.

Tipos estáticos y genéricos

Verificación de tipos en compilación, genéricos y errores claros antes de ejecutar, como en C# y Java.

Memoria segura

Ownership y préstamos sin recolector de basura, para rendimiento de C sin sus errores de memoria. Ya existe en el núcleo experimental.

Biblioteca estándar completa

Red, HTTP con TLS, hilos, bases de datos y criptografía estables y probados en las tres plataformas.

Interoperabilidad con C

Llamar cualquier librería de C desde C-Forge para aprovechar todo el ecosistema existente.

Herramientas profesionales

Gestor de paquetes, servidor de lenguaje (LSP) completo y depurador.

Preguntas frecuentes

Respuestas directas.

¿C-Forge es compilado o interpretado?

Las dos cosas, según el comando. cforge programa.cfv lo ejecuta con el motor nativo de C-Forge, sin compilar. cforge build programa.cfv traduce tu programa a C y lo compila con gcc o clang para obtener un ejecutable. El compilador propio, sin herramientas externas, está en desarrollo.

¿Necesito instalar algo más?

No para ejecutar programas: el instalador deja todo listo. Solo cforge build necesita gcc o clang en tu equipo.

¿Es tan rápido como C o C++?

Todavía no. El motor actual prioriza que el lenguaje sea correcto y estable. El compilador nativo propio de la hoja de ruta es el paso para alcanzar ese rendimiento.

¿Puedo usarlo en producción?

Para scripts, herramientas y aprendizaje, sí: el núcleo, la CLI y la biblioteca estable pasan las pruebas en las tres plataformas. Red, SQLite, criptografía y gráficos siguen siendo experimentales, y C-Forge todavía no está certificado para sistemas críticos como banca. La sección Estado lo detalla.

¿Las palabras clave se pueden escribir en inglés?

No por ahora. C-Forge usa palabras clave en español: sea, funcion, si, mientras, retornar, entre otras.

¿Cuánto cuesta?

Nada. C-Forge es código abierto con licencia MIT y lo desarrolla Vemoris Group.

Encontré un error, ¿dónde lo reporto?

En los issues de GitHub. Si incluyes el archivo .cfv y la salida de cforge doctor, mejor.
